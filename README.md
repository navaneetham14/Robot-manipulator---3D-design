# 🤖 Robotic Arm Design Using SOLIDWORKS

## 📌 Project Overview
This project focuses on the 3D design and assembly of a robotic arm using SOLIDWORKS. 
The model consists of a structural base, multiple mechanical linkages, rotating joints, 
and a robotic gripper designed for object handling.

The project demonstrates mechanical design, 3D part modelling, and assembly techniques 
used in robotics and automation applications.

## 🎯 Objectives
- Design individual mechanical components using SOLIDWORKS.
- Develop linkages and joints for robotic arm movement.
- Create a stable base for supporting the robotic structure.
- Assemble multiple components into a complete robotic arm.
- Improve practical knowledge of CAD modelling and mechanical design.

## 🛠️ Software Used
- **CAD Software:** SOLIDWORKS 2026
- **Design Method:** 3D Parametric Modelling
- **Assembly Tools:** Mates and Component Assembly
- **Features Used:** Extrude, Revolve, Cut, Chamfer, Fillet, Mirror, and Circular Pattern

## ⚙️ Main Components
1. **Base:** Supports the robotic arm structure.
2. **ELSABON 1:** Mechanical linkage component.
3. **ELSABON 2:** Connecting arm linkage.
4. **ELSABON 3:** Shaft and mounting component.
5. **ELSABON 4:** Joint and linkage component.
6. **ELSABON 5:** Rotating support component.
7. **ELSABON 6:** Linkage mounting component.
8. **PINZAS:** Gripper mechanism component.
9. **Robot Hand:** Robotic gripper assembly.

## 🔧 Design Features
- 3D modelling of individual components.
- Mechanical linkage and joint integration.
- Rotational component arrangement.
- Component assembly using SOLIDWORKS mates.
- Base design with mounting provisions.
- Gripper mechanism for potential object handling.
